SQL analysis queries

Q1 — Correlation strength

Which pairs of numeric variables have the strongest linear relationship?

SELECT col_a, col_b, ROUND(correlation_coefficient, 3) AS r, CASE WHEN ABS(correlation_coefficient) > 0.7 THEN 'Strong' WHEN ABS(correlation_coefficient) > 0.4 THEN 'Moderate' ELSE 'Weak' END AS strength FROM correlation_matrix WHERE col_a <> col_b ORDER BY ABS(correlation_coefficient) DESC LIMIT 10;
