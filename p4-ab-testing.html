Pipeline architecture

01
Generate data

Simulate 10,000 users (5K control / 5K treatment) with realistic conversion rates, cart values, and device mix

02
Chi-square test

Build contingency table [converted/not × control/treatment], compute chi-square statistic and p-value

03
Confidence interval

Calculate 95% CI on conversion rate difference using normal approximation standard error

04
Segment analysis

Break results by device (mobile/desktop/tablet) to check if effect holds across sub-groups

05
Revenue projection

Multiply (CR_treatment - CR_control) × monthly_visitors × avg_cart_value for business impact

06
Business recommendation

Print SHIP or DO NOT SHIP recommendation with p-value, CI, and projected monthly revenue uplift

SQL analysis queries

Q1 — Conversion rates
Q2 — Device segment

Core conversion rate comparison between control and treatment variants.

SELECT variant, COUNT(*) AS total_users, SUM(converted) AS conversions, ROUND(100.0 * SUM(converted) / COUNT(*), 2) AS conversion_rate_pct, ROUND(AVG(cart_value), 2) AS avg_cart_value, ROUND(AVG(time_on_page_sec), 0) AS avg_time_sec FROM ab_test_results GROUP BY variant;

Conversion rate broken down by device type for each variant.

SELECT variant, device, COUNT(*) AS users, SUM(converted) AS conversions, ROUND(100.0 * SUM(converted) / COUNT(*), 2) AS conversion_pct, ROUND(AVG(cart_value), 2) AS avg_cart FROM ab_test_results GROUP BY variant, device ORDER BY device, variant;
