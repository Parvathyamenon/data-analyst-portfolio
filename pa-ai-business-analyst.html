Pipeline architecture

01
Transcript input

User pastes meeting transcript (or uses built-in sample from realistic Amazon-style product meeting)

02
Output selection

User selects: BRD requirements, BDD user stories, acceptance criteria, risks & dependencies, success KPIs

03
Prompt engineering

System prompt specifies exact BA output format: REQ-001 numbering, priority rating, stakeholder source

04
Ollama AI call

POST to localhost:11434 with transcript; Mistral extracts structured requirements in ~15 seconds

05
Structured output

Numbered requirements with Priority + Source; testable Given-When-Then stories; measurable acceptance criteria

06
Download

User can download complete requirements document as .txt file directly from the app

SQL analysis queries

Q1 — Requirements by priority

How many requirements were extracted at each priority level?

SELECT priority, COUNT(*) AS requirement_count, GROUP_CONCAT(req_id, ', ') AS req_ids FROM requirements_log GROUP BY priority ORDER BY CASE priority WHEN 'High' THEN 1 WHEN 'Medium' THEN 2 ELSE 3 END;
